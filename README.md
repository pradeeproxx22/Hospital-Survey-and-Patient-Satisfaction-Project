## 🏥 Project Overview

This project focuses on analyzing healthcare service quality and patient satisfaction using Data Science techniques. Survey data was collected through Google Forms and processed using Python for data cleaning, preprocessing, and exploratory data analysis (EDA). Machine Learning models were developed to identify patterns and predict patient satisfaction based on various healthcare service factors. Interactive dashboards were created in Power BI to visualize key insights and trends. Finally, the trained model was integrated into a Flask web application, allowing users to make real-time predictions through a simple and user-friendly interface.
