## 🏥 Project Overview

This project focuses on analyzing healthcare service quality and predicting patient satisfaction using Data Science and Machine Learning techniques. Survey data was collected, cleaned, and transformed to perform exploratory data analysis and uncover meaningful insights. Predictive models were developed to estimate patient satisfaction based on healthcare service factors. An interactive Power BI dashboard was created for data visualization, and the final model was deployed using Flask for real-time predictions. This project showcases the complete Data Science lifecycle, from data collection to model deployment.
